# ApexSales – Executive Sales Dashboard

A modern, high-contrast interactive dashboard built to provide real-time financial monitoring. This project represents the final stage of the Sales Analysis track.

## ✨ Key Features
- **KPI Metrics:** Real-time tracking of Revenue, Units Sold, and Average Order Value (AOV).
- **Interactive Visuals:** Plotly charts that allow for data hovering and dynamic scaling.
- **Monthly Trend Tracking:** Time-series analysis to identify seasonal peaks.
- **Regional Donut Chart:** Visualizes market share distribution with a modern UI.
- **Detailed Order Log:** A styled data table for granular transaction inspection.

## ⚡ Technical Highlights
- **Performance:** Implemented `@st.cache_data` for lightning-fast data loading.
- **UI/UX:** Custom CSS injection for a professional "Dark Mode" aesthetic.
- **Responsiveness:** Wide-layout configuration for high-resolution displays.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Graphics:** Plotly Express
- **Analysis:** Pandas
