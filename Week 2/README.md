# GradeBoost! – Interactive Grade Calculator

A Flask-based web application designed to help students calculate academic performance and receive motivational feedback.

## Features
- **Dynamic Calculation:** Processes numerical marks to determine Grade (A-F).
- **Interactive UI:** Built with HTML5 and CSS3 using absolute positioning for a layered design.
- **Immediate Feedback:** Displays specific badges and motivational messages based on results.
- **Validation:** Includes logic to handle out-of-range inputs (0-100).

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3 (Flexbox, Absolute Positioning)

## 📖 How to Run
1. Install Flask: `pip install flask`
2. Run `python gradecalculator.py`
3. Visit `http://127.0.0.1:5000/`
